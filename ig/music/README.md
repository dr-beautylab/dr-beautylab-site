# 릴스 배경음악 보관함 (세 계정 공용)

- 출처: 뚝딱컷 무료 음악 https://jiwon-info.co.kr/music/shorts/ (매장 홍보 릴스·쇼츠에 무료 사용 가능하다고 안내된 AI 연주곡. 2026-11-23 내려받음)
- 파일: `<코드>.mp3` — 곡에서 가장 좋은 구간 45초만 잘라 둔 것. 소리 크기는 -14 LUFS로 맞춰져 있음.
- 목록: `catalog.json` — code, title, genre, mood, bpm, seconds, beats(파일 시작 기준 박자 시각·초), last_used.

## 쓰는 법
1. 영상 분위기에 맞는 곡을 catalog.json에서 고른다. last_used가 최근인 곡은 피해서 돌려 쓴다. 같은 계정에서 3주 안에 같은 곡 금지.
2. 영상은 0초 = mp3의 0초로 맞춘다. 장면 전환·카드 등장 시각은 beats에 있는 값으로 맞춘다(ig/tools/build_music.py 참고).
3. 끝 1.2초는 소리를 줄이며 끝낸다. 영상 길이는 13~17초 권장.
4. 쓴 뒤 catalog.json의 last_used에 "날짜 계정 주제"를 적는다.

## 계정별 어울리는 곡
- 당신을그리다: 화사·차분·어쿠스틱(nm088, fs005, fs012, fs019, fs020, c12, c13, c16, c24 등). 12월엔 x로 시작하는 크리스마스 재즈.
- 닥터뷰티랩: 세련·차분(fs005, nm082, nm083, c06, fs003, fs010 등).
- 합격연구소: 경쾌한 정보형(nm080 꿀팁 타이머, b23, b02, fs001, nm081 등).

인스타 앱 안의 유행 음악은 자동 게시로 붙일 수 없고, 유행곡을 파일로 넣으면 저작권 문제로 소리가 지워질 수 있어 쓰지 않는다.
